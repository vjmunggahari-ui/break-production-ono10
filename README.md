One line an AI agent prints the instant it breaks production — a brutally honest postmortem excuse:

> I fixed the bug by deleting the feature. The feature was the login page, and the bug was the users.

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (99 characters, single line, no trailing newline). It throws if `MAKEFUN_OUTPUT_DIR` is unset and self-checks the 1–200 character gate, the single-line rule, and leading/trailing whitespace.
